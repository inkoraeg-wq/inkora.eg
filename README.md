# 🕷️ INKORA — Streetwear & Fashion Brand

Welcome to the official web repository for **INKORA**, an Egyptian streetwear brand combining modern street culture, dark aesthetic visual style, and premium visual layout.

---

## 🌟 Features
- **Modern Dark Visual Aesthetic:** Designed to reflect streetwear culture and bold typography.
- **Product Showcase:** Interactive display for drops, collections, and signature pieces.
- **Responsive Layout:** Optimized for smooth browsing across Desktop, Tablet, and Mobile screens.
- **Fast & Lightweight:** Built with standard web technologies for minimal load times and optimal performance.

---

## 🛠️ Built With
- **HTML5:** Semantic architecture and core content structuring.
- **CSS3:** Custom styles, dark aesthetic palette, and responsive design grid.
- **JavaScript (ES6):** Dynamic interactions and smooth user interface mechanisms.
